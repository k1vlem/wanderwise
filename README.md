# Pangea

Сайт, который планирует поездку в любую из 20 самых посещаемых стран мира под ваш бюджет: перелёт, отель, достопримечательности и еда на каждый день. Школьный бизнес-проект, бета-версия.

**Сайт:** https://k1vlem.github.io/wanderwise/

*A trip planner for the world's 20 most visited countries, built around one number: your budget. School business project, beta.*

## Что умеет

- **Спланируйте за меня.** Человек вводит бюджет, даты, число путешественников и интересы. Планировщик сам подбирает страну или город, класс отеля, перелёт и уровень еды, чтобы всё влезло в бюджет, и расписывает каждый день по часам. Учитывает выходные дни музеев (например, музеи Ватикана закрыты по воскресеньям). План можно поправить кнопками «Дешевле», «Больше вкусной еды», «Меньше ходить», «Другой маршрут».
- **Соберу сам.** Конструктор, где человек выбирает город, перелёт, отель 3★/4★/5★, достопримечательности и бюджет на еду. Шкала бюджета пересчитывается после каждого выбора.
- **Аккаунты и «Мои поездки».** Регистрация, сохранённые черновики, демо-бронирование и расписание по дням с билетами.
- **7 языков:** English, Русский, Español, Deutsch, Français, Italiano, Türkçe. Язык определяется по браузеру и переключается в шапке.
- **20 стран, 40 городов**, по данным UN Tourism о турпотоке за 2024 год: топ-10 Европы (Франция, Испания, Италия, Турция, Греция, Великобритания, Германия, Австрия, Португалия, Нидерланды) и топ-10 за её пределами (США, Китай, Мексика, Япония, Таиланд, ОАЭ, Саудовская Аравия, Малайзия, Вьетнам, Марокко). Можно выбрать страну, целый регион или «куда угодно».
- **Перелёты по расстоянию.** 22 города вылета, от Лондона и Москвы до Алматы, Нью-Йорка и Сиднея. Цена и время в пути считаются по расстоянию между аэропортами. После длинного перелёта первый день оставлен на отдых.

## Что пока демонстрационное

- Цены — оценки в евро на высокий сезон, а не живые цены. Реальные цены можно подключить через партнёрские API (авиабилеты через Travelpayouts, отели через Booking, экскурсии через GetYourGuide).
- Аккаунты и поездки хранятся только в браузере (localStorage). Для настоящих аккаунтов нужен сервер, например Supabase.
- Бронирование — демо: деньги не списываются.
- Планировщик — наш алгоритм, он работает прямо в браузере. Подключить нейросеть (Claude API) можно следующим шагом: для этого нужен API-ключ и небольшой сервер.

## Запуск у себя

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # сайт на http://localhost:5173/wanderwise/
npm run build    # сборка в папку dist
```

## Как устроено

| Папка | Что внутри |
|---|---|
| `src/data/` | Страны, города, достопримечательности, блюда, города вылета. Все названия на 7 языках |
| `src/lib/planner.ts` | Планировщик: подбор поездки под бюджет и расписание по дням |
| `src/i18n/` | Переводы интерфейса, по файлу на язык |
| `src/pages/` | Страницы: главная, страна, планировщик, конструктор, вход, мои поездки, бронирование |
| `src/components/` | Шапка, подвал, фото, расписание, шкала бюджета |
| `public/photos/` | Фотографии и список авторов (`credits.json`) |

Стек: React 18, TypeScript, Vite, Tailwind CSS. Сайт публикуется на GitHub Pages автоматически при каждом пуше в `main`: задача `.github/workflows/deploy.yml` собирает сайт и кладёт его в ветку `gh-pages`, откуда его раздаёт GitHub Pages.

## Фотографии

Фото — главные изображения статей Википедии, скачанные с Wikimedia Commons. Их скачивает GitHub Actions (`.github/workflows/photos.yml`) по списку из `photos.manifest.json`. Чтобы заменить фото, поменяйте статью (`wiki`) или укажите файл Commons (`file`) в манифесте и запушьте. Авторы и лицензии видны на странице «Авторы фото».

## Как добавить язык

1. Скопируйте `src/i18n/en.ts` в новый файл, например `kk.ts`, и переведите строки.
2. Добавьте код языка в `LANGS` в `src/data/types.ts`, а название в `LANG_NAMES` в `src/i18n/index.tsx`.
3. Добавьте перевод названий в данные (`src/data/`): TypeScript покажет, где не хватает строк.
